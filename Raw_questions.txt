# Prompting

## Q28. Types of Prompting

| Type | Description |
|------|-------------|
| Zero-shot | No examples — model uses its own knowledge |
| One-shot | One example provided |
| Few-shot | Multiple examples provided |
| Chain-of-thought | Step-by-step reasoning |
| ReAct | Reason + Act (for agents) |
| System prompting | Role/persona defined in system message |

---

## Q29. What is Jailbreaking?

Jailbreaking is an attempt to bypass an LLM's safety guardrails using crafted prompts to make it produce restricted content.

Examples: prompt injection, role-play manipulation, encoding tricks.

---

## Q30. Guardrail Techniques

- **Input validation** — filter harmful inputs before sending to LLM
- **Output validation** — check LLM output before returning to user
- **Content filters** — AWS Bedrock Guardrails, OpenAI moderation API
- **Prompt injection detection**
- **PII detection and redaction**
- **Hallucination detection** — semantic similarity between source and output

---

# Cloud & Integrations

## Q31. What is Redis and its Use Cases?

Redis is an in-memory key-value store used for caching, sessions, and pub/sub.

### Use Cases in AI Applications

- Caching LLM responses
- Session storage (chat history)
- Rate limiting
- Job queues (Celery + Redis)
- Pub/Sub for streaming

---

## Q32. Stateful vs Stateless Servers

| Stateless | Stateful |
|-----------|----------|
| No session data stored | Session data stored on server |
| Scales easily | Harder to scale |
| REST APIs (JWT) | WebSockets, chat sessions |
